## GAP CLOSURE CALCULATOR

### **Effort to Coverage Ratio (ROI Analysis)**

**Highest ROI (Effort per High-Yield Percent Coverage):**
1. **H&P/Differential Methodology** — 18–22h, unlocks ALL other learning (foundation)
2. **Pneumonia + Stewardship** — 12–14h for very high frequency (saves morbidity/mortality cost)
3. **Stroke** — 8–10h, time-critical, high mortality, high intern responsibility
4. **COPD + Asthma** — ~11h combined for very high frequency
5. **CAD/ACS** — 7–8h for high mortality + high frequency

**Medium ROI:**
6. **Diabetes** — 10–12h, very high frequency, lower acute mortality (more chronic)
7. **Meningitis** — 6–7h, lower frequency but catastrophic mortality
8. **Thyroid Disease** — 6–8h, high frequency but lower acute mortality

**Lower ROI (but still important):**
9. **PE/DVT** — 10–12h effort; critical diagnosis but some coverage exists
10. **GI Bleeding** — 8–10h; existing partial coverage (55%)
11. **Hematology** — 15–17h; niche competency (HIT critical; anemia routine)

## PHASE MAPPING QUICK VIEW

### **PHASE 1: WEEKS 1–4 (50–65 hours, 550–750 units)**
Foundation + emergencies that unlock everything else

- [ ] H&P/Differential Methodology (18–22h) — **UNLOCK ALL**
- [ ] EBM Fundamentals (6–8h)
- [ ] Stroke Recognition (8–10h) — **EMERGENT**
- [ ] Seizures + Status Epilepticus (6–7h) — **EMERGENT**
- [ ] Meningitis (6–7h) — **EMERGENT**

**Dependency:** Downstream modules require these foundations.

### **PHASE 2: WEEKS 5–12 (65–75 hours, 1000–1200 units)**
High-frequency diagnoses that dominate intern year

- [ ] Pneumonia + Antibiotic Stewardship (12–14h) — **VERY HIGH FREQUENCY**
- [ ] Cardiovascular: Valvular + ACS (15–17h) — **HIGH MORTALITY**
- [ ] Pulmonary: COPD + Asthma + PE/DVT (14–16h) — **VERY HIGH FREQUENCY + MORTALITY**
- [ ] GI Bleeding (8–10h)
- [ ] Renal: AKI/CKD (6–8h)
- [ ] Endocrinology: Diabetes + Thyroid + Adrenal (16–20h) — **VERY HIGH FREQUENCY**

**Checkpoint:** ~1500–1700 new medicine units live; 70% of critical gaps closed.

## SUCCESS BENCHMARKS

### **Phase 1 Validation (Week 4)**
- [ ] Intern can score NIHSS + interpret stroke imaging
- [ ] Intern recognizes status epilepticus + knows seizure drug dosing
- [ ] Intern orders empiric meningitis antibiotics correctly (age-stratified)
- [ ] Intern creates differential diagnosis for 3 presentations (dyspnea, chest pain, altered mental status)
- **Gate:** Proceed to Phase 2 if ≥3/4 met

### **Phase 2 Validation (Week 12)**
- [ ] Intern uses CURB-65 + selects empiric pneumonia antibiotics
- [ ] Intern interprets troponin kinetics + EKG in ACS scenario
- [ ] Intern risk-stratifies PE (Wells score, D-dimer decision)
- [ ] Intern manages GI bleeding (transfusion thresholds, PPI dosing)
- [ ] Intern calculates A1C targets + insulin regimen
- **Gate:** Proceed to Phase 3 if ≥4/5 met; ~1500+ new units live

### **Phase 3 Completion (Week 20)**
- [ ] Intern identifies HIT vs. ITP
- [ ] Intern manages alcohol withdrawal (CIWA-Ar, benzodiazepine dosing)
- [ ] Intern calculates Child-Pugh score in cirrhosis
- [ ] Intern interprets CSF in differential diagnosis
- [ ] Intern communicates advance directives to patient/family
- **Final:** ≥4/5 met; ~2500–3000 intern medicine units live

## CONTINGENCY PLANS

### **If Sourcing Delayed**
Prioritize in order:
1. UpToDate access (if institutional subscription exists)
2. Free CDC/IDSA/AHA resources (public domain)
3. Washington Manual (library/used copy)
4. Defer specialty guideline PDFs if public version available

### **If Chunking Capacity Limited**
Phase prioritization:
1. **Critical + High (Weeks 1–12) → 100% effort**
2. **Medium (Weeks 13–16) → 50% effort (highest-ROI topics only)**
3. **Lower-priority → Defer to next cycle**

### **If Integration Conflicts Arise**
- Create separate "intern medicine" library tag vs. "anesthesiology_boards"
- Curriculum builder can weight libraries by user role (anesthesia CA-1 vs. medicine intern)
- Avoid merging until validated that anesthesia + medicine frameworks complement
